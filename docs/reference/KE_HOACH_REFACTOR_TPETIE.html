2.1. Nguyên Tắc Kiến Trúc

Separation of Concerns (SoC)

  • Presentation: Chỉ render UI, không chứa business logic
  • API Layer: Validate, authorize, route — không query DB trực tiếp
  • Service Layer: Toàn bộ logic nghiệp vụ (tính giá, kiểm stock, tạo đơn)
  • Data Access: CRUD thuần qua Prisma, không chứa logic

Dependency Inversion (DI)

  • Tầng trên không phụ thuộc tầng dưới trực tiếp
  • Service inject Repository qua interface
  • Dễ dàng swap DB provider mà không ảnh hưởng logic
  • Unit test được từng tầng độc lập

3.3.1 — Loại bỏ AuthContext fallback users

Xoá hoàn toàn mảng FALLBACK_USERS và logic so sánh password trên client. Mọi authentication đi qua NextAuth server-side authorize → Prisma query.

// TRƯỚC (AuthContext.tsx — LỖ HỔNG BẢO MẬT) const FALLBACK_USERS: User[] = [ { email: 'admin@tpetie.vn', password: 'admin123', role: 'admin' }, ... ]; // SAU (Xoá hoàn toàn, chỉ dùng NextAuth hooks) export function useAuth() { const { data: session, status } = useSession(); return { user: session?.user, isLoading: status === 'loading' }; }
3.3.2 — Chuyển products.json → Server-side fetch

Thay vì import 162KB JSON tĩnh vào client bundle, chuyển sang Server Component fetch từ DB với ISR caching.
